## 5. Trampas aprendidas (no repetir)

* **Jamás `cargo run --example X`** en este entorno (interactivo, cuelga el
  timeout) — y ojo con `.exe` zombies que bloquean el linker (LNK1104):
  `Get-Process showroom,blank,...` + `Stop-Process` antes de rebuild.
* **Caracteres invisibles (NF/PUA) NO se escriben a mano**: siempre escapes
  ASCII `\u{...}`; si algo raro entra, fix con script Python por nº de línea.
* `cargo fmt` refluye bloques → **leer antes de cada `edit`** (varios
  "oldString not found" fueron por esto).
* `u16` aritmética SIEMPRE con `saturating_*` (debug paniquea).
* Borrow checker: precalcular `bounds`/datos antes de `frame()` mutable.
* Commits atómicos por rama según su propósito (docs vs built vs help);
  `target/` y `Cargo.lock` ignorados (lib).
